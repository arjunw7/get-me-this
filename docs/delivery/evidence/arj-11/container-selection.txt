# ARJ-11 — database container selection (exact project, fail closed)

scripts/db-seed.sh never seeds an arbitrary 'supabase_db_' container. It
reads project_id from supabase/config.toml and requires both:
  * Docker label com.supabase.cli.project=<project_id>, and
  * an exact container name of supabase_db_<project_id>.
It fails closed unless exactly one container matches.

The selector is Bash 3.2-compatible so it also runs on macOS; see
bash-3-2-compatibility.txt for the mapfile reproduction and the fix.
